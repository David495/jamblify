# Jamblify - JAMB Exam Preparation Platform

[![Next.js](https://img.shields.io/badge/Next.js-000000?style=for-the-badge&logo=nextdotjs&logoColor=white)](https://nextjs.org/)
[![TypeScript](https://img.shields.io/badge/TypeScript-007ACC?style=for-the-badge&logo=typescript&logoColor=white)](https://www.typescriptlang.org/)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-38B2AC?style=for-the-badge&logo=tailwind-css&logoColor=white)](https://tailwindcss.com/)
[![Appwrite](https://img.shields.io/badge/Appwrite-F02E65?style=for-the-badge&logo=appwrite&logoColor=white)](https://appwrite.io/)

Jamblify is a comprehensive JAMB (Joint Admissions and Matriculation Board) exam preparation platform that helps students prepare for their university entrance exams through smart practice tests, personalized feedback, and AI-powered study tools.

## Features

- 🎯 AI-powered practice tests
- 📊 Performance analytics
- 🧠 Personalized study recommendations
- 📱 Responsive design
- 🔒 Secure authentication
- 📝 Practice with past questions

## Tech Stack

- **Frontend**: Next.js 14, React 19, TypeScript
- **Styling**: Tailwind CSS
- **Backend**: Appwrite
- **AI**: Google Generative AI
- **Animation**: AOS (Animate On Scroll)
- **Icons**: Lucide Icons

## Getting Started

### Prerequisites

- Node.js 18.0.0 or later
- npm or yarn
- Appwrite instance (for authentication)

### Installation

1. Clone the repository:
   ```bash
   git clone [https://github.com/yourusername/jamblify.git](https://github.com/David495/jamblify.git)
   ```
